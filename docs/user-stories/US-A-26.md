# US-A-26: Управлять хранилищем файлов (видео, изображения, вложения)

## Цель story
Администратор должен уметь управлять хранилищем файлов (видео, изображения, вложения), чтобы очищать неиспользуемые файлы и контролировать объём.

Эпик: `Техническое обслуживание и поддержка`.
Контур: `MVP`.
Приоритет: `Средний`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Хранилище»: общий объём, занято по типам (видео, изображения, прочее).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Раздел «Хранилище»: общий объём, занято по типам (видео, изображения, прочее).

2. Список самых больших файлов с указанием курса/урока.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Список самых больших файлов с указанием курса/урока.

3. Возможность удалить файл (с проверкой, используется ли он в уроках).
   Статус: ожидание.
   Контур: Развитие 1 очереди.
   Что включено: Возможность удалить файл (с проверкой, используется ли он в уроках).

4. Запуск задачи на очистку «сиротских» файлов (не привязанных ни к одному курсу).
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Что включено: Запуск задачи на очистку «сиротских» файлов (не привязанных ни к одному курсу).

## Что считать готовностью story
- Раздел «Хранилище»: общий объём, занято по типам (видео, изображения, прочее).
- Список самых больших файлов с указанием курса/урока.
