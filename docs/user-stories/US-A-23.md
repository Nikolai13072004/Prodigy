# US-A-23: Просматривать системные логи (ошибки, предупреждения) и скачивать их для отладки

## Цель story
Администратор должен уметь просматривать системные логи (ошибки, предупреждения) и скачивать их для отладки, чтобы быстро находить причины сбоев.

Эпик: `Техническое обслуживание и поддержка`.
Контур: `Развитие 1 очереди`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Логи»: выбор уровня (error, warning, info), фильтр по времени, поиск.
   Статус: ожидание.
   Контур: Развитие 1 очереди.
   Что включено: Раздел «Логи»: выбор уровня (error, warning, info), фильтр по времени, поиск.

2. Просмотр логов в реальном времени (tail -f через WebSocket).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Просмотр логов в реальном времени (tail -f через WebSocket).

3. Кнопка «Скачать логи за период» (ZIP).
   Статус: ожидание.
   Контур: Развитие 1 очереди.
   Что включено: Кнопка «Скачать логи за период» (ZIP).

4. Настройка уровня детализации логов (debug/production).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Настройка уровня детализации логов (debug/production).
