# US-C-08: Установить дату начала и окончания доступа к курсу (или срок прохождения)

## Цель story
Разработчик курсов должен уметь установить дату начала и окончания доступа к курсу (или срок прохождения), чтобы создать ограниченные по времени курсы (например, марафоны).

Эпик: `Управление доступом и группами`.
Контур: `Не использовать`.
Приоритет: `Низкий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. В настройках курса: дата открытия, дата закрытия.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: В настройках курса: дата открытия, дата закрытия.

2. Индивидуальное продление доступа для конкретного ученика.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Индивидуальное продление доступа для конкретного ученика.

3. При приближении дедлайна — автоматические напоминания ученикам.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: При приближении дедлайна — автоматические напоминания ученикам.

## Что считать готовностью story
- В настройках курса: дата открытия, дата закрытия.
- Индивидуальное продление доступа для конкретного ученика.
- При приближении дедлайна — автоматические напоминания ученикам.
