# US-A-29: Импортировать пользователей из CSV с возможностью обновлять существующих

## Цель story
Администратор должен уметь импортировать пользователей из CSV с возможностью обновлять существующих, чтобы мигрировать данные из старой системы.

Эпик: `Импорт/экспорт и миграции`.
Контур: `Не использовать`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Форма загрузки CSV с маппингом колонок (email, name, role).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Форма загрузки CSV с маппингом колонок (email, name, role).

2. Опции: «Создавать новых», «Обновлять существующих по email», «Пропускать дубликаты».
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Опции: «Создавать новых», «Обновлять существующих по email», «Пропускать дубликаты».

3. Предпросмотр первых 5 строк с валидацией.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Предпросмотр первых 5 строк с валидацией.

4. Отчёт об импорте: сколько создано, обновлено, ошибок.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Отчёт об импорте: сколько создано, обновлено, ошибок.

## Что считать готовностью story
- Форма загрузки CSV с маппингом колонок (email, name, role).
- Опции: «Создавать новых», «Обновлять существующих по email», «Пропускать дубликаты».
- Предпросмотр первых 5 строк с валидацией.
- Отчёт об импорте: сколько создано, обновлено, ошибок.
