# US-A-12: Модерировать комментарии (удалять/редактировать/закреплять) и обрабатывать жалобы пользователей

- Раздел «Жалобы»: список жалоб на комментарии с указанием автора жалобы, комментария, причины.
- При просмотре жалобы – кнопки: «Удалить комментарий», «Оставить как есть», «Предупредить автора».
