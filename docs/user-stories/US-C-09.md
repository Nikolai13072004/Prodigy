# US-C-09: Видеть агрегированную статистику по курсу (средний прогресс, количество завершивших, средняя оценка, воронка удержания)

## Цель story
Разработчик курсов должен уметь видеть агрегированную статистику по курсу (средний прогресс, количество завершивших, средняя оценка, воронка удержания), чтобы оценить эффективность материала.

Эпик: `Аналитика и обратная связь`.
Контур: `Не использовать`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Дашборд с метриками: всего учеников, завершили %, средний прогресс, средний рейтинг, количество отзывов.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Дашборд с метриками: всего учеников, завершили %, средний прогресс, средний рейтинг, количество отзывов.

2. График удержания: сколько учеников дошли до каждого модуля.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: График удержания: сколько учеников дошли до каждого модуля.

3. Распределение оценок (гистограмма).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Распределение оценок (гистограмма).

## Что считать готовностью story
- Дашборд с метриками: всего учеников, завершили %, средний прогресс, средний рейтинг, количество отзывов.
- График удержания: сколько учеников дошли до каждого модуля.
- Распределение оценок (гистограмма).
