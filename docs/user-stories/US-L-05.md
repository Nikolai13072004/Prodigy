# US-L-05: Выполнять встроенные тесты и задания (выбор ответа, эссе, файл)

## Цель story
Ученик должен уметь выполнять встроенные тесты и задания (выбор ответа, эссе, файл), чтобы проверять свои знания.

Эпик: `Запись и управление обучением`.
Контур: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. После отправки теста мгновенно показывается результат и правильные ответы (для закрытых вопросов).
   Статус: ожидание.
   Контур: MVP.
   Что включено: После отправки теста мгновенно показывается результат и правильные ответы (для закрытых вопросов).

2. Для заданий с проверкой преподавателем — статус «На проверке».
   Статус: ожидание.
   Контур: MVP.
   Что включено: Для заданий с проверкой преподавателем — статус «На проверке».

3. Есть возможность загрузить файл (с ограничением по типу и размеру).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Есть возможность загрузить файл (с ограничением по типу и размеру).

4. Ограничение числа попыток (если задано автором курса).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Ограничение числа попыток (если задано автором курса).

## Что считать готовностью story
- После отправки теста мгновенно показывается результат и правильные ответы (для закрытых вопросов).
- Для заданий с проверкой преподавателем — статус «На проверке».
- Есть возможность загрузить файл (с ограничением по типу и размеру).
- Ограничение числа попыток (если задано автором курса).
