# US-A-21: Настраивать автоматические отчёты (еженедельная сводка по email)

## Цель story
Администратор должен уметь настраивать автоматические отчёты (еженедельная сводка по email), чтобы получать регулярные срезы без ручного экспорта.

Эпик: `Мониторинг, аналитика и отчёты`.
Контур: `Не использовать`.
Приоритет: `Низкий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Отчёты → Расписание»: создать отчёт (например, «Новые пользователи за неделю»), выбрать получателей (email админов).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Раздел «Отчёты → Расписание»: создать отчёт (например, «Новые пользователи за неделю»), выбрать получателей (email админов).

2. Формат: PDF, CSV, HTML в теле письма.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Формат: PDF, CSV, HTML в теле письма.

3. Возможность приостановить/удалить расписание.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Возможность приостановить/удалить расписание.

4. Лог отправленных отчётов.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Лог отправленных отчётов.

## Что считать готовностью story
- Раздел «Отчёты → Расписание»: создать отчёт (например, «Новые пользователи за неделю»), выбрать получателей (email админов).
- Формат: PDF, CSV, HTML в теле письма.
