# US-HR-01: Просматривать список всех курсов (опубликованных) с информацией о количестве записанных учеников

## Цель story
HR должен уметь просматривать список всех курсов (опубликованных) с информацией о количестве записанных учеников, чтобы выбирать курсы для назначения сотрудникам.

Эпик: `Управление записями на курсы (назначение и отчисление)`.
Контур: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Отображается таблица курсов: название, автор, категория, длительность, количество уже записанных учеников (всего и из моей организации, если есть фильтр по группам).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Отображается таблица курсов: название, автор, категория, длительность, количество уже записанных учеников (всего и из моей организации, если есть фильтр по группам).

2. Фильтры по категории, уровню сложности.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Фильтры по категории, уровню сложности.

3. Поиск по названию курса.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Поиск по названию курса.

4. При клике на курс – переход к странице с деталями и списком учеников (если есть доступ).
   Статус: ожидание.
   Контур: MVP.
   Что включено: При клике на курс – переход к странице с деталями и списком учеников (если есть доступ).

## Что считать готовностью story
- Отображается таблица курсов: название, автор, категория, длительность, количество уже записанных учеников (всего и из моей организации, если есть фильтр по группам).
- Фильтры по категории, уровню сложности.
- Поиск по названию курса.
- При клике на курс – переход к странице с деталями и списком учеников (если есть доступ).
