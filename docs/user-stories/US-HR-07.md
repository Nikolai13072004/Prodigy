# US-HR-07: Видеть сводную информацию по всем ученикам (независимо от курса)

## Цель story
HR должен уметь видеть сводную информацию по всем ученикам (независимо от курса), чтобы понимать общую картину обучения в организации.

Эпик: `Мониторинг прогресса и успеваемости`.
Контур: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Все ученики»: список пользователей с ролью «Ученик» (ФИО, email, отдел/группа, количество записанных курсов, завершённых курсов).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Раздел «Все ученики»: список пользователей с ролью «Ученик» (ФИО, email, отдел/группа, количество записанных курсов, завершённых курсов).

2. Фильтры по группе/отделу, по дате регистрации.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Фильтры по группе/отделу, по дате регистрации.

3. При клике на ученика – страница с его личным прогрессом по всем курсам.
   Статус: ожидание.
   Контур: MVP.
   Что включено: При клике на ученика – страница с его личным прогрессом по всем курсам.

4. Поиск по имени или email.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Поиск по имени или email.

## Что считать готовностью story
- Раздел «Все ученики»: список пользователей с ролью «Ученик» (ФИО, email, отдел/группа, количество записанных курсов, завершённых курсов).
- Фильтры по группе/отделу, по дате регистрации.
- При клике на ученика – страница с его личным прогрессом по всем курсам.
- Поиск по имени или email.
