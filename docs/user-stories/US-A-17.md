# US-A-17: Управлять интеграциями (SSO, S3 для файлов, вебхуки, платёжные шлюзы)

## Цель story
Администратор должен уметь управлять интеграциями (SSO, S3 для файлов, вебхуки, платёжные шлюзы), чтобы подключать внешние сервисы.

Эпик: `Глобальные настройки платформы`.
Контур: `Развитие 2 очереди`.
Приоритет: `Средний`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Интеграции»: вкладки – SSO (LDAP, OAuth2, SAML), S3 (ключи, bucket), вебхуки (список, тестирование), платежи (Stripe/PayPal).
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Что включено: Раздел «Интеграции»: вкладки – SSO (LDAP, OAuth2, SAML), S3 (ключи, bucket), вебхуки (список, тестирование), платежи (Stripe/PayPal).

2. Для каждой интеграции – форма с API-ключами, тестовое соединение.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Что включено: Для каждой интеграции – форма с API-ключами, тестовое соединение.

3. Включение/отключение интеграции без удаления данных.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Что включено: Включение/отключение интеграции без удаления данных.

4. Логирование ошибок интеграции.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Что включено: Логирование ошибок интеграции.
