# US-A-28: Просматривать историю обращений в поддержку (если встроен тикет-система)

## Цель story
Администратор должен уметь просматривать историю обращений в поддержку (если встроен тикет-система), чтобы отслеживать проблемы пользователей.

Эпик: `Поддержка пользователей (имперсонация и помощь)`.
Контур: `Не использовать`.
Приоритет: `Низкий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Поддержка»: список тикетов от пользователей (тема, дата, статус).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Раздел «Поддержка»: список тикетов от пользователей (тема, дата, статус).

2. Возможность оставить внутренний комментарий (виден только админам).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Возможность оставить внутренний комментарий (виден только админам).

3. Изменять статус: открыт, в работе, решён, закрыт.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Изменять статус: открыт, в работе, решён, закрыт.

4. Отправлять ответ пользователю через интерфейс (email).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Отправлять ответ пользователю через интерфейс (email).

## Что считать готовностью story
- Раздел «Поддержка»: список тикетов от пользователей (тема, дата, статус).
- Возможность оставить внутренний комментарий (виден только админам).
- Изменять статус: открыт, в работе, решён, закрыт.
- Отправлять ответ пользователю через интерфейс (email).
