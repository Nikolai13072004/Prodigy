# US-C-06: Видеть список учеников, записанных на мой курс, с их прогрессом

## Цель story
Разработчик курсов должен уметь видеть список учеников, записанных на мой курс, с их прогрессом, чтобы отслеживать активность.

Эпик: `Управление доступом и группами`.
Контур: `Не использовать`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Таблица учеников: имя, email, дата записи, % прогресса, дата последнего визита.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Таблица учеников: имя, email, дата записи, % прогресса, дата последнего визита.

2. Фильтры по статусу (активен/завершил/бросил).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Фильтры по статусу (активен/завершил/бросил).

3. Экспорт в CSV/Excel.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Экспорт в CSV/Excel.

## Что считать готовностью story
- Таблица учеников: имя, email, дата записи, % прогресса, дата последнего визита.
- Фильтры по статусу (активен/завершил/бросил).
- Экспорт в CSV/Excel.
