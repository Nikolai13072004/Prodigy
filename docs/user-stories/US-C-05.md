# US-C-05: Сохранять черновик и публиковать курс только после полной готовности

## Цель story
Разработчик курсов должен уметь сохранять черновик и публиковать курс только после полной готовности, чтобы ученики не видели недоделанный материал.

Эпик: `Управление контентом курса`.
Контур: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Кнопка «Сохранить черновик» (автосохранение каждые 30 секунд).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Кнопка «Сохранить черновик» (автосохранение каждые 30 секунд).

2. Перед публикацией — валидация: заполнены ли обязательные поля, есть ли хотя бы один модуль/урок.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Перед публикацией — валидация: заполнены ли обязательные поля, есть ли хотя бы один модуль/урок.

3. После публикации курс становится виден ученикам (если не скрыт администратором).
   Статус: ожидание.
   Контур: MVP.
   Что включено: После публикации курс становится виден ученикам (если не скрыт администратором).

4. Возможность снять с публикации (вернуть в черновик) с предупреждением для записанных учеников.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Возможность снять с публикации (вернуть в черновик) с предупреждением для записанных учеников.

## Что считать готовностью story
- Кнопка «Сохранить черновик» (автосохранение каждые 30 секунд).
- Перед публикацией — валидация: заполнены ли обязательные поля, есть ли хотя бы один модуль/урок.
- После публикации курс становится виден ученикам (если не скрыт администратором).
- Возможность снять с публикации (вернуть в черновик) с предупреждением для записанных учеников.
