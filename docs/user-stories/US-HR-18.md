# US-HR-18: Просматривать прогресс по группе (отделу) – средний прогресс по курсам, количество завершивших

## Цель story
HR должен уметь просматривать прогресс по группе (отделу) – средний прогресс по курсам, количество завершивших, чтобы сравнивать эффективность разных отделов.

Эпик: `Управление группами/отделами (опционально, для крупных организаций)`.
Контур: `Не использовать`.
Приоритет: `Низкий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. В разделе «Группы» – при клике на группу отображается сводка: список учеников группы, их прогресс по обязательным курсам.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: В разделе «Группы» – при клике на группу отображается сводка: список учеников группы, их прогресс по обязательным курсам.

2. График: средний прогресс по группе в сравнении с другими группами.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: График: средний прогресс по группе в сравнении с другими группами.

3. Экспорт отчёта по группе.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Экспорт отчёта по группе.

4. Фильтр по курсу (если назначено несколько курсов).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Фильтр по курсу (если назначено несколько курсов).

## Что считать готовностью story
- В разделе «Группы» – при клике на группу отображается сводка: список учеников группы, их прогресс по обязательным курсам.
- График: средний прогресс по группе в сравнении с другими группами.
- Экспорт отчёта по группе.
- Фильтр по курсу (если назначено несколько курсов).
