# US-A-11: Модерировать отзывы на курсы (скрывать/восстанавливать нежелательные отзывы)

## Цель story
Администратор должен уметь модерировать отзывы на курсы (скрывать/восстанавливать нежелательные отзывы), чтобы поддерживать корректную обратную связь.

Эпик: `Модерация контента и отзывов`.
Контур: `Не использовать`.
Приоритет: `Средний`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Раздел «Модерация отзывов»: список всех отзывов с фильтрами по курсу, статусу (опубликован/скрыт), дате.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Раздел «Модерация отзывов»: список всех отзывов с фильтрами по курсу, статусу (опубликован/скрыт), дате.

2. Для каждого отзыва – кнопки «Скрыть» (с причиной) и «Восстановить».
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Для каждого отзыва – кнопки «Скрыть» (с причиной) и «Восстановить».

3. Скрытый отзыв не виден ученикам, но виден автору отзыва и админу.
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Скрытый отзыв не виден ученикам, но виден автору отзыва и админу.

4. Возможность массового действия (выбрать несколько отзывов → скрыть).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Возможность массового действия (выбрать несколько отзывов → скрыть).

## Что считать готовностью story
- Раздел «Модерация отзывов»: список всех отзывов с фильтрами по курсу, статусу (опубликован/скрыт), дате.
- Для каждого отзыва – кнопки «Скрыть» (с причиной) и «Восстановить».
- Скрытый отзыв не виден ученикам, но виден автору отзыва и админу.
- Возможность массового действия (выбрать несколько отзывов → скрыть).
