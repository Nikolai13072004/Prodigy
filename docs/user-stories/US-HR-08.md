# US-HR-08: Просматривать результаты тестов и заданий учеников (оценки, комментарии проверяющего)

## Цель story
HR должен уметь просматривать результаты тестов и заданий учеников (оценки, комментарии проверяющего), чтобы оценить качество усвоения материала.

Эпик: `Мониторинг прогресса и успеваемости`.
Контур: `MVP`.
Приоритет: `Средний`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. На странице детального прогресса ученика – список тестов и заданий по курсу.
   Статус: ожидание.
   Контур: MVP.
   Что включено: На странице детального прогресса ученика – список тестов и заданий по курсу.

2. Для теста: отображается дата попытки, балл, порог прохождения, результат (сдал/не сдал).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Для теста: отображается дата попытки, балл, порог прохождения, результат (сдал/не сдал).

3. Для задания: статус (на проверке/проверено), оценка, комментарий разработчика курса.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Для задания: статус (на проверке/проверено), оценка, комментарий разработчика курса.

4. Возможность экспорта результатов по всем ученикам курса в CSV (оценки).
   Статус: ожидание.
   Контур: MVP.
   Что включено: Возможность экспорта результатов по всем ученикам курса в CSV (оценки).

## Что считать готовностью story
- На странице детального прогресса ученика – список тестов и заданий по курсу.
- Для теста: отображается дата попытки, балл, порог прохождения, результат (сдал/не сдал).
- Для задания: статус (на проверке/проверено), оценка, комментарий разработчика курса.
- Возможность экспорта результатов по всем ученикам курса в CSV (оценки).
