# US-A-07: Просматривать все курсы (включая черновики, архивные, удалённые)

## Цель story
Администратор должен уметь просматривать все курсы (включая черновики, архивные, удалённые), чтобы контролировать наполнение платформы.

Эпик: `Управление курсами (надзор и контроль)`.
Контур: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Таблица курсов: ID, название, автор, статус (черновик/опубликован/архив), количество учеников, дата создания.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Таблица курсов: ID, название, автор, статус (черновик/опубликован/архив), количество учеников, дата создания.

2. Фильтры по статусу, автору, категории.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Что включено: Фильтры по статусу, автору, категории.

3. Поиск по названию.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Поиск по названию.

4. Переход на страницу курса для детального просмотра (как ученик или редактор).
   Статус: ожидание.
   Контур: Развитие 1 очереди.
   Что включено: Переход на страницу курса для детального просмотра (как ученик или редактор).

## Что считать готовностью story
- Таблица курсов: ID, название, автор, статус (черновик/опубликован/архив), количество учеников, дата создания.
- Поиск по названию.

## Возможные следующие улучшения, но не блокеры для story
- Фильтры по статусу, автору, категории. Контур: `Развитие 2 очереди`.
- Переход на страницу курса для детального просмотра (как ученик или редактор). Контур: `Развитие 1 очереди`.
