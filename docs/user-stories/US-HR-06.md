# US-HR-06: Просматривать список учеников, записанных на конкретный курс, с их прогрессом (проценты, завершённые уроки, результаты тестов)

## Цель story
HR должен уметь просматривать список учеников, записанных на конкретный курс, с их прогрессом (проценты, завершённые уроки, результаты тестов), чтобы отслеживать вовлечённость.

Эпик: `Мониторинг прогресса и успеваемости`.
Контур: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Ожидание`.

## Шаги реализации
1. Таблица учеников курса: ФИО, email, дата записи, % прогресса, статус (активен/завершил/бросил), дата последнего визита.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Таблица учеников курса: ФИО, email, дата записи, % прогресса, статус (активен/завершил/бросил), дата последнего визита.

2. Сортировка по любому столбцу, фильтр по статусу.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Сортировка по любому столбцу, фильтр по статусу.

3. Возможность кликнуть на ученика, чтобы увидеть детальный прогресс по модулям/урокам.
   Статус: ожидание.
   Контур: MVP.
   Что включено: Возможность кликнуть на ученика, чтобы увидеть детальный прогресс по модулям/урокам.

4. Экспорт текущего списка в CSV (кнопка).
   Статус: ожидание.
   Контур: Не использовать.
   Что включено: Экспорт текущего списка в CSV (кнопка).

## Что считать готовностью story
- Таблица учеников курса: ФИО, email, дата записи, % прогресса, статус (активен/завершил/бросил), дата последнего визита.
- Сортировка по любому столбцу, фильтр по статусу.
- Возможность кликнуть на ученика, чтобы увидеть детальный прогресс по модулям/урокам.

## Возможные следующие улучшения, но не блокеры для story
- Экспорт текущего списка в CSV (кнопка). Контур: `Не использовать`.
