# Ролевая модель (группы доступов)

## Группы и доступы

### Пользователи
- Просмотр пользователей
- Создание пользователей
- Изменение персональной информации о пользователе
- Изменение уровня доступа пользователя
- Удаление пользователя

### Группы
- Просмотр группы
- Создание групп
- Редактирование групп
- Удаление групп

### Подразделения
- Просмотр подразделений
- Создание и редактирование подразделений
- Удаление подразделений

### Курсы
- Просмотр курсов
- Создание и редактирование курсов
- Удаление курсов
- Управление назначениями

### Отчеты
- Просмотр отчетов по курсам и пользователям

### Управление обучением
- Проверка знаний

## Матрица текущих ролей в LMS

В текущей реализации приложения используются роли `ADMIN` и `USER`.

- `ADMIN`:
  - полный доступ ко всем группам и доступам.
- `USER`:
  - `Курсы`: Просмотр курсов
  - `Управление обучением`: Проверка знаний

## Реализация в коде

- Справочник групп/доступов: `src/lib/roles.ts`
- Карта доступов ролей: `ROLE_PERMISSIONS` в `src/lib/roles.ts`
- Профили ролей в БД: таблица `RoleProfile` (`prisma/schema.prisma`)
- CRUD ролей: `src/app/actions/role-actions.ts`
- Проверки маршрутов: `src/auth.ts`
- Guard-слой server actions/pages: `src/lib/auth-guards.ts`
- Отрисовка пунктов меню по правам: `src/components/AppShellClient.tsx`
- Страницы:
  - список ролей: `/admin/roles`
  - создание роли: `/admin/roles/new`
  - настройки роли: `/admin/roles/[id]`
