# US-C-01: Создать новый курс с базовыми метаданными (название, описание, категория, уровень сложности, обложка)

Источник: `Копия Юзер-сторис_MVP.xlsx` + `Юзер-сторис.xlsx`.

## Цель story
Разработчик курсов должен уметь создать новый курс с базовыми метаданными (название, описание, категория, уровень сложности, обложка), чтобы затем наполнить его контентом.

Эпик: `Управление контентом курса`.
Контур текущего среза: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Сделано`.

## Шаги реализации
1. Форма создания курса с полями: название (обяз.), описание (обяз.), категория (выбор из справочника), уровень (нач/сред/продв), длительность (ч/мин), обложка (jpg/png, ограничение 5МБ).
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

2. После создания курс получает статус «Черновик» и доступен только автору и администратору.
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

3. Автоматически присваивается ID курса.
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

## Что считать готовностью story
- Форма создания курса с полями: название (обяз.), описание (обяз.), категория (выбор из справочника), уровень (нач/сред/продв), длительность (ч/мин), обложка (jpg/png, ограничение 5МБ).
- После создания курс получает статус «Черновик» и доступен только автору и администратору.
- Автоматически присваивается ID курса.
