# US-A-25: Управлять API-токенами для интеграций (создавать, отзывать, ограничивать права)

Источник: `Копия Юзер-сторис_MVP.xlsx` + `Юзер-сторис.xlsx`.

## Цель story
Администратор должен уметь управлять API-токенами для интеграций (создавать, отзывать, ограничивать права), чтобы безопасно подключать внешние системы.

Эпик: `Техническое обслуживание и поддержка`.
Контур текущего среза: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Готово`.

## Шаги реализации
1. Раздел «API»: список токенов (название, дата создания, последний использован, scope).
   Статус: готово.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

2. Создание токена: указать название, выбрать разрешения (например, только courses:read).
   Статус: ожидание.
   Контур: Развитие 1 очереди.
   Входит в обновлённый MVP-срез: нет.

3. Сгенерированный токен показывается один раз.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Входит в обновлённый MVP-срез: нет.

4. Кнопка «Отозвать» – токен мгновенно перестаёт работать.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Входит в обновлённый MVP-срез: нет.

## Что считать готовностью story
- Раздел «API»: список токенов (название, дата создания, последний использован, scope).
