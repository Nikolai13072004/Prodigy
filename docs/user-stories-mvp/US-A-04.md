# US-A-04: Удалять пользователей (мягкое удаление – архивация) или полностью стирать из системы

Источник: `Копия Юзер-сторис_MVP.xlsx` + `Юзер-сторис.xlsx`.

## Цель story
Администратор должен уметь удалять пользователей (мягкое удаление – архивация) или полностью стирать из системы, чтобы соблюдать требования GDPR или чистить тестовые аккаунты.

Эпик: `Управление пользователями и ролями`.
Контур текущего среза: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Готово`.

## Шаги реализации
1. При удалении – предупреждение о последствиях: потеря прогресса, сертификатов, курсов (если автор).
   Статус: готово.
   Контур: Не использовать.
   Входит в обновлённый MVP-срез: нет.

2. Опция «Мягкое удаление» – пользователь помечается как удалённый, но данные сохраняются для отчётности.
   Статус: готово.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

3. Опция «Полное удаление» – безвозвратное удаление всех данных (с подтверждением через ввод пароля).
   Статус: ожидание.
   Контур: Не использовать.
   Входит в обновлённый MVP-срез: нет.

4. Нельзя удалить самого себя.
   Статус: готово.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

## Что считать готовностью story
- Опция «Мягкое удаление» – пользователь помечается как удалённый, но данные сохраняются для отчётности.
- Нельзя удалить самого себя.

- Опция «Полное удаление» – безвозвратное удаление всех данных (с подтверждением через ввод пароля). Контур: `Не использовать`. Статус: `Ожидание`.
