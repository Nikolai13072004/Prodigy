# US-C-02: Добавлять в курс модули и уроки (с поддержкой разных типов контента: текст, видео, тест, задание с файлом)

Источник: `Копия Юзер-сторис_MVP.xlsx` + `Юзер-сторис.xlsx`.

## Цель story
Разработчик курсов должен уметь добавлять в курс модули и уроки (с поддержкой разных типов контента: текст, видео, тест, задание с файлом), чтобы структурировать материал.

Эпик: `Управление контентом курса`.
Контур текущего среза: `MVP`.
Приоритет: `Высокий`.
Текущий статус: `Сделано`.

## Шаги реализации
1. Возможность создавать модули (разделы), внутри модуля — уроки.
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

2. Для каждого урока выбрать тип:
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

3. - Текст (WYSIWYG-редактор)
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

4. - Видео (ссылка YouTube/Vimeo или загрузка файла)
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

5. - Тест (множественный выбор, одиночный, соответствие)
   Статус: сделано.
   Контур: MVP.
   Входит в обновлённый MVP-срез: да.

6. - Задание (описание + прикрепление файла учеником)
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Входит в обновлённый MVP-срез: нет.

7. Drag-and-drop для переупорядочивания модулей и уроков.
   Статус: ожидание.
   Контур: Развитие 2 очереди.
   Входит в обновлённый MVP-срез: нет.

8. Предпросмотр урока как ученик.
   Статус: ожидание.
   Контур: Развитие 1 очереди.
   Входит в обновлённый MVP-срез: нет.

## Что считать готовностью story
- Возможность создавать модули (разделы), внутри модуля — уроки.
- Для каждого урока выбрать тип:
- - Текст (WYSIWYG-редактор)
- - Видео (ссылка YouTube/Vimeo или загрузка файла)
- - Тест (множественный выбор, одиночный, соответствие)
