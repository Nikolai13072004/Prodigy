# MVP User Stories

Источник: `Копия Юзер-сторис_MVP.xlsx`.

Всего документов: 35.

Отдельный индекс: [MVP + высокий](./README-MVP-HIGH.md).
Тест-кейсы для приёмки и регрессии: [TEST_CASES_MVP](./TEST_CASES_MVP.md).

Каждый story-файл дополнен полным перечнем шагов из `Юзер-сторис.xlsx`, чтобы сразу видеть `MVP`-готовность и следующие улучшения.

## Адмимнистратор системы

- [US-A-01](./US-A-01.md) — Просматривать список всех пользователей с фильтрацией по роли, статусу (активен/заблокирован), дате регистрации
- [US-A-02](./US-A-02.md) — Создавать пользователей (вручную или через CSV), назначать им роли и отправлять приглашения
- [US-A-03](./US-A-03.md) — Редактировать любого пользователя (изменять имя, email, роль, сбрасывать пароль, блокировать/разблокировать)
- [US-A-04](./US-A-04.md) — Удалять пользователей (мягкое удаление – архивация) или полностью стирать из системы
- [US-A-05](./US-A-05.md) — Управлять ролями и разрешениями (создавать кастомные роли, назначать наборы разрешений)
- [US-A-07](./US-A-07.md) — Просматривать все курсы (включая черновики, архивные, удалённые)
- [US-A-14](./US-A-14.md) — Настраивать общие параметры системы (название платформы, логотип, контакты поддержки)
- [US-A-15](./US-A-15.md) — Настраивать email-уведомления (SMTP-сервер, шаблоны писем, от кого отправлять)
- [US-A-16](./US-A-16.md) — Настраивать политики безопасности (сложность пароля, двухфакторная аутентификация, время жизни сессии)
- [US-A-22](./US-A-22.md) — Переключать платформу в режим обслуживания (maintenance mode)
- [US-A-25](./US-A-25.md) — Управлять API-токенами для интеграций (создавать, отзывать, ограничивать права)
- [US-A-26](./US-A-26.md) — Управлять хранилищем файлов (видео, изображения, вложения)

## Разработчик курсов

- [US-C-01](./US-C-01.md) — Создать новый курс с базовыми метаданными (название, описание, категория, уровень сложности, обложка)
- [US-C-02](./US-C-02.md) — Добавлять в курс модули и уроки (с поддержкой разных типов контента: текст, видео, тест, задание с файлом)
- [US-C-03](./US-C-03.md) — Настроить условия доступа к урокам (свободно / последовательно / после прохождения теста)
- [US-C-04](./US-C-04.md) — Загружать видео-уроки прямо на платформу или встраивать из внешних источников
- [US-C-05](./US-C-05.md) — Сохранять черновик и публиковать курс только после полной готовности
- [US-C-12](./US-C-12.md) — Редактировать опубликованный курс без потери прогресса учеников

## HR

- [US-HR-01](./US-HR-01.md) — Просматривать список всех курсов (опубликованных) с информацией о количестве записанных учеников
- [US-HR-02](./US-HR-02.md) — Назначить одного или нескольких учеников на курс (по email или из списка существующих пользователей)
- [US-HR-05](./US-HR-05.md) — Продлить доступ ученика к курсу (если курс имеет срок годности)
- [US-HR-06](./US-HR-06.md) — Просматривать список учеников, записанных на конкретный курс, с их прогрессом (проценты, завершённые уроки, результаты тестов)
- [US-HR-07](./US-HR-07.md) — Видеть сводную информацию по всем ученикам (независимо от курса)
- [US-HR-08](./US-HR-08.md) — Просматривать результаты тестов и заданий учеников (оценки, комментарии проверяющего)
- [US-HR-09](./US-HR-09.md) — Получать уведомления о завершении курса учеником (или о низкой активности)
- [US-HR-10](./US-HR-10.md) — Формировать отчёт по курсу (список учеников, прогресс, оценки, статус завершения) в формате CSV/Excel
- [US-HR-11](./US-HR-11.md) — Формировать сводный отчёт по всем курсам (сколько учеников записано, завершило, средний прогресс)
- [US-HR-13](./US-HR-13.md) — Создавать новых учеников (например, новых сотрудников) и приглашать их на платформу
- [US-HR-16](./US-HR-16.md) — Блокировать ученика (например, при увольнении)

## Ученик

- [US-L-01](./US-L-01.md) — Видеть каталог всех доступных мне курсов с фильтрацией по категориям, тегам и уровню сложности
- [US-L-02](./US-L-02.md) — Открыть карточку курса с детальной информацией (программа, требования, список тем, отзывы)
- [US-L-04](./US-L-04.md) — Проходить уроки в структурированном порядке (последовательное открытие тем или свободная навигация, в зависимости от настроек курса)
- [US-L-05](./US-L-05.md) — Выполнять встроенные тесты и задания (выбор ответа, эссе, файл)
- [US-L-06](./US-L-06.md) — Видеть свой общий прогресс по курсу (% завершения, количество пройденных уроков/тестов)
- [US-L-09](./US-L-09.md) — Оставить отзыв и рейтинг пройденному курсу
